# 주점 기능 구현 현황

축제 플랫폼의 **주점(Pub) 기능만** 공개하는 구현 현황 페이지입니다.

- 구현 현황: https://khu-adelante-26-2.github.io/pub-implementation-status/
- 연결 와이어프레임: https://khu-adelante-26-2.github.io/pub-implementation-status/wireframes.html
- 표시 범위: 주점 사용자용 iPad, 사용자 휴대폰 대기 현황, 직원용 관리자 휴대폰
- 판정 근거: 요구사항별 실제 코드와 자동 테스트
- 주의: 자동 테스트 통과는 별도 QA 완료를 뜻하지 않습니다.

현황 판정과 진행률 계산은 원본 개발 저장소의 `update-pub-ev` 절차에서 수행합니다. 기기별 연결 와이어프레임은 별도 `update-pub-wireframes` 절차로 관리합니다. 공개 HTML 원본은 이 저장소에만 둡니다.
